# App de Organização de Finanças Pessoais com Vibe Coding – Giovanna

## PRD refinado no Copilot

```markdown
PRD – App de Organização de Finanças Pessoais

1. Contexto
Criar um aplicativo de organização de finanças pessoais que funcione por meio de conversas em linguagem natural, permitindo que o usuário controle seus gastos sem precisar lidar com formulários complexos ou planilhas.

2. Problema
- Usuários desistem de controlar suas finanças porque os apps atuais exigem entrada manual excessiva.
- Falta de personalização e de uma experiência mais fluida.
- Necessidade de uma solução simples, acessível e motivadora.

3. Público-Alvo
- Pessoas que desejam começar a organizar suas finanças de forma prática.
- Principalmente iniciantes que não têm familiaridade com planilhas ou apps tradicionais.

4. Funcionalidades-Chave
1. Registro de gastos via chat em linguagem natural.
2. Classificação automática das transações (ex.: alimentação, transporte, lazer).
3. Definição e acompanhamento de metas financeiras (ex.: poupar R$200/mês).
4. Agente Financeiro: dicas de economia e recomendações personalizadas.
5. Relatórios simples e personalizados (gráficos e resumos).

5. Princípios de Design
- O aplicativo deve seguir os princípios de Design Universal, garantindo que a experiência seja acessível, inclusiva e agradável para o maior número possível de usuários, independentemente de idade, nível de experiência digital ou possíveis limitações físicas/cognitivas.
- Exemplos: interface clara, suporte a leitores de tela, linguagem simples, contrastes adequados, navegação intuitiva.

6. Entregável da IA
- Plano de MVP com:
  - Principais telas (chat, metas, relatórios).
  - Recursos necessários (NLP para interpretar linguagem natural, categorização automática, motor de recomendações).
  - Esboço de validação inicial (testar com grupo pequeno de usuários iniciantes).
- Linguagem acessível e educativa, em português.
```

## Funcionalidades do App de Finanças Pessoais

### 1. Registro de gastos via chat
- O usuário interage em linguagem natural, sem precisar preencher formulários complexos.
- O sistema interpreta automaticamente as mensagens e registra as transações.

### 2. Classificação automática das transações
- As despesas são categorizadas (ex.: alimentação, transporte, lazer) sem esforço manual.
- Facilita relatórios e análises personalizadas.

### 3. Metas financeiras
- O usuário define objetivos como “Reserva de Emergência” ou “Viagem de Férias”.
- O app mostra o progresso em porcentagem e valores já acumulados.
- Interface visual com barras de progresso coloridas, tornando o acompanhamento simples e motivador.

### 4. Agente Financeiro (assistente conversacional)
- Oferece dicas de economia e recomendações personalizadas.
- Funciona como um “amigo financeiro” que conversa e orienta o usuário.

### 5. Relatórios personalizados
- Gráficos e resumos acessíveis para visualizar gastos e evolução das metas.
- Navegação intuitiva com abas de “Chat”, “Metas” e “Relatórios”.

### 6. Princípios de Design Universal
- Interface clara e inclusiva, com contraste adequado e linguagem simples.
- Compatibilidade com leitores de tela e navegação intuitiva.
- Experiência pensada para o maior número possível de usuários, independentemente de idade ou limitações.

## Reflexão sobre o processo

- **O que funcionou bem?**  
  O refinamento do PRD feito no Copilot foi de grande ajuda para a execução do projeto no Lovable.

- **O que não funcionou como o esperado?**  
  O Lovable requer mais treinamento para melhor execução, sendo assim, leva tempo ou dinheiro para um desempenho mais otimizado.

- **O que aprendeu sobre conversar com IAs?**  
  As IAs precisam de informações bem detalhadas para boa compreensão do pedido. Quanto mais específico for, mais próximo o resultado será.
